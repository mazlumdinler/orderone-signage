Menu Boards

Each menu page shown in rotation on the TV is a "board." Add as many as you like.

    Select a menu board on the left, or create a new one.

    Square POS Connection

    Enter your Square Access Token here to match your items with your catalog in Square. The name shown on the TV and the name in Square don't have to match — you set up the matching separately for each item.

    You can get your token from the Square Developer Dashboard → Applications → Credentials. Once saved, the token will not be shown on screen again.

    Cached Square Products

    Product/variation list pulled in after the last sync. Match products from each menu item's edit form.

    Connected Screens

    While the /display page is open on a TV, it sends a "live" signal here roughly every 60 seconds. If no signal is received for more than 2 minutes, the screen is considered offline.

    How to open on a TV?

    On your LG TV's browser (or a media player box), open the following address in full screen:

    /display

    The page automatically rotates through all active boards and refreshes menu changes on its own every 30 seconds — there's no need to restart the TV.
